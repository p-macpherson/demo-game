# Technical Direction

> The technical targets and rules the game's code follows: performance, resolution, structure, testing, and how
> polished code should be at this stage.

## For now
No technical targets have been set. Write the simplest code that works and keep it easy to change; cover behaviour the
game depends on with a scripted test.

## To decide
- **Targets.** Frame rate, resolution, minimum hardware, load times.
- **Code structure.** How the game package is organised and the patterns to keep to.
- **Quality bar.** How robust code must be at this stage (throwaway prototype or production), and what must have tests.
- **Budgets.** Limits on triangles, texture sizes, draw calls, audio channels, memory.
