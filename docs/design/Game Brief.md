# Game Brief

> Goblin Gold: a small goblin wanders a mossy clearing looking for treasure. Demo Game is the sandbox Game Studio is
> developed against, so the game stays deliberately small: big enough to show every studio module working together,
> small enough to change in an afternoon.

Written on 2026-11-21 from what was already in the game and its old Overview; Pat hasn't reviewed it as a doc yet, hence draft.

## Pitch
A small goblin wanders a mossy clearing looking for treasure. Walk up to a chest, open it, and celebrate the gold
inside. Find every chest to win.

## Genre and references
A tiny third-person exploration toy: no enemies, no fail state.

## Player and platform
Single player, desktop, keyboard and mouse.

## Scope
One scene, a few minutes of play. Deliberately left out: enemies, inventory, saving, menus beyond the title, pause and
win screens.

## Stage
A showcase: every part of the game is made in a Game Studio module, and the game grows when a new module needs
something to show. What's in it now is listed in [Content](Content.md).
