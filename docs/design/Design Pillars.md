# Design Pillars

> Three principles every choice in Goblin Gold is checked against: readable at a glance, every action has a reaction,
> made in the studio.

Written on 2026-11-21 from what was already in the game and its old Overview; Pat hasn't reviewed it as a doc yet, hence draft.

## Pillars
- **Readable at a glance.** Chunky, stylised models and a calm palette; the goblin is always the clearest thing on screen.
- **Every action has a reaction.** Walking animates, chests creak open, the goblin waves when it finds gold.
- **Made in the studio.** Every asset comes from a Game Studio module (models from 3D Models, code from Game Code
  sessions), so the game doubles as a showcase of the pipeline.
